둘째 행은 `tools/vc.sh hvac 'recirc=true'`로 하트비트를 켠 채 돌렸다. 준비 때 `tools/vc.sh hvac 'recirc=true'` 뒤 2초 간격으로 다섯 번 읽은 콘솔 값이 모두 true였다. 복원이 빠른 것은 ×240 압축에서 시뮬레이션 5분이 실제 1.25초이기 때문이다. 콘솔 값은 0.25초 간격으로 읽었고 false 구간은 약 2.0초였다(94.2초 false, 96.3초 true, 시나리오 버튼 직전부터 잰 초). 이번 실행에서는 "응" 직후 표본(94초) 하나가 `Vehicle SDK로 공기 모드 변경: 바깥 공기`까지만 보였고, 다음 표본(96초)부터 ", 이후 재순환으로 복원"이 붙었다. 855d, 07dd 실행도 같았다. 8eb5 실행에서는 "응" 뒤 첫 표본(92초)부터 붙어 있었다. 덤프 간격(약 2초)에 따라 그 순간이 잡히거나 잡히지 않는다. 앱 창 화면은 1초 간격 화면 캡처로 따로 남겼다.

셋째 행은 따로 만든 조건이 아니라 README 문장대로다. 둘째 행 실행 뒤 `tools/vc.sh hb-stop`만 하고 SC2를 다시 눌렀더니, 앱이 재순환으로 복원해 둔 값 때문에 V27을 묻고 값이 바뀌지 않았다(실행 내내 콘솔 값 true). 첫째 행은 셋 중 맨 먼저, README대로 시나리오 직전에 `tools/vc.sh hvac 'recirc=false'`를 넣고 하트비트를 끈 뒤 돌렸다(실행 내내 콘솔 값 false, 앱 logcat `HVAC_RECIRC_ON eventValue false`). 실행 순서는 SC1, SC2(첫째 행), SC3, SC2(둘째 행), SC2(셋째 행)이다.
